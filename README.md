# Camilo Tapia
### Software Developer

¡Hola! 👋 Soy Camilo, un desarrollador de software que encuentra su mayor motivación en transformar ideas en sistemas escalables y experiencias interactivas. Para mí, escribir código es el puente perfecto entre la lógica técnica y la creatividad.

Me muevo con naturalidad entre distintas etapas y áreas del desarrollo. Por un lado, disfruto estructurando arquitecturas backend robustas, gestionando flujos de mensajes y creando pipelines de despliegue en la nube mediante contenedores. Por otro, tengo un lado fuertemente creativo que me lleva a programar mecánicas personalizadas para videojuegos y a explorar flujos de modelado y retopología 3D. 

Creo firmemente en la planificación y el diseño previo a la codificación. Antes de tirar la primera línea de código, me gusta utilizar herramientas de diagramación y gestión para aterrizar ideas, mantener el orden y tener una visión integral clara de cada proyecto.

---

### 💻 Tecnologías y Áreas de Experiencia

- **Mobile (Android):** Kotlin, Arquitectura MVVM, Retrofit, Room.
- **Backend & Cloud:** Spring Boot (Java), Node.js, Microservicios, RabbitMQ, Docker, AWS, Azure, JWT.
- **Frontend & UI:** React, JavaScript, Figma.
- **Game Dev & 3D:** Lua, Roblox Studio, Blender.
- **Tools & Management:** Postman, Miro, draw.io, ProjectLibre.
