### Sobre mí

Hola, soy Camilo. Soy desarrollador de software y actualmente curso mi tercer año de Ingeniería en Informática en Duoc UC. Me dedico a construir aplicaciones desde cero, enfocándome en lograr un equilibrio entre un código limpio, una arquitectura sólida y un buen rendimiento.

Veo cada proyecto como una oportunidad para aprender algo nuevo y dejar el código mejor de lo que lo encontré. A nivel profesional, busco integrarme a equipos que utilicen metodologías ágiles. Mi meta a largo plazo es asumir roles de gestión y liderazgo, como Scrum Master o Tech Lead, para aportar valor tanto en el área técnica como en la organización del equipo.
